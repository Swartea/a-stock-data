### 债 1：结论与操作自相矛盾（严重，已修 ✅）

**现象**：报告"🔴 看空 43 分｜不建议进场（清仓回避）"，但操作口诀写"现价分两批进场、持有 3-6 个月"。

**根因**：模板只套了买入结构，未按多空结论切换操作模板。

**修法**（Task 5.1，commit `75408bb`）：V3 加多空状态机（5 状态）+ 5 套独立"结论+操作+风险"三段模板：
- 阈值与 `report-design-principles.md:88-94` 仓位 5 档对齐：≥65 多 / 55-65 轻多 / 45-55 中性 / 35-45 轻空 / <35 空
- 模板：bullish（分批进场 3-6 月） / mild_bull（轻仓试探 10-20%） / neutral（区间操作 + 止损） / mild_bear（减仓至轻仓） / bearish（清仓回避）

**实测**：
- 600693 score=45 → state=neutral → "区间操作 — 上沿 12.67 减仓、下沿 11.17 低吸、严格止损 9.95"
- 002353 杰瑞股份 score=56 → state=mild_bull → "轻仓试探 10-20%，等综合评分回升至 65+ 确认后加仓"

### 债 2：缺支撑/压力显式字段（严重，已修 ✅）

**现象**：老板硬要求"结论 + 支撑/压力/止损"缺一不可。当前只有止损/止盈（其实是"现价 +X%"反推的），没有真正从技术面算出的支撑/压力。

**修法**（Task 5.2，commit `422af48`）：V3 加 `compute_three_levels`（4 候选取最近者）：
- 支撑候选：MA60 / recent_low（60 日最低）/ chip_peak / boll_lower（取最低且 ≤ 1.05×现价）
- 压力候选：MA250_or_MA120 / recent_high（60 日最高）/ boll_upper（取最高且 ≥ 0.95×现价）
- 字段注入 `result["three_levels"] = {support, resistance, stop_loss, support_candidates, resistance_candidates, method}`
- stop_loss **复用** `trading_plan.stop_loss`（不重算，避免与 Task 5.1 锁定字段冲突）
- 字段名修正：V3 实际 K 线在 `chip_data["kline"]`（无 `technical.*`），peak_price 平铺（不在 `cost_concentration` 子键）

**实测**：
- 600693：支撑=7.16 (recent_low) / 压力=11.90 (recent_high) / 止损=9.95（复用 trading_plan）
- 002353：支撑=105.00 (MA60) / 压力=176.59 (recent_high) / 止损=116.90（复用 trading_plan）

### 债 3：北向资金 370.5 亿口径异常（已修 ✅）

**现象**：报告写"✅ 北向净流入 370.5亿"。美湖股份流通市值 102 亿，全市场当日北向净流入 370 亿才算合理。

**根因**：数据源把"全市场北向净流入"当个股口径填入了。

**修法**（Task 5.3 + round 1，commit `06904ca` + `7d02959`）：
1. **V3 加 helper 函数** `_classify_north_scope(north_data) -> (scope, label)`：根据接口字段推断 scope（market/stock/mixed/unknown），生成带 scope 标签的 label 字符串
2. **V3 注入字段** `result["macro"]["north_scope"]` + `["north_label"]`
3. **MD 渲染器改读** `north_label`（不再 hardcode "北向净流入 {total} 亿"）
4. **v2 factor note 也加 scope 标签**（round 1）：`quant_analyzer_v2.py` line 953-954 情绪因子 `factors.append("北向资金(全市场)净流入...")` 而非旧版 "北向净流入..."，避免 good_signals 段误读

**接口字段名实测 vs plan 假设**（plan 假设字段与 V3 实际不符，worker 主动适配）：
- 全市场总净流入：实际 `total_yi`（plan 假设 `total` / `north_net`）❌ → helper 多别名识别
- 沪股通：实际 `latest_hgt_yi`（plan 假设 `sh` / `sh_net`）❌
- 深股通：实际 `latest_sgt_yi`（plan 假设 `sz` / `sz_net`）❌

**实测**：

**现象**：原 PEG = `pe_fwd / cagr_pct`，600693 算得 3.85，与 ifind 41.73 偏差 -91%。
