## 2. 定稿美化规范（改造目标）

### 2.1 设计 token（CSS 变量，全篇统一）
- 中性底 `#fafaf9`、文字 `#1c1917`（不纯黑纯白）
- 强调 `#2563eb`、警告 `#d97706`、危险 `#dc2626`、正向 `#16a34a`
- 分隔线 hairline `#e7e5e4`
- **A 股例外（红涨绿跌，覆盖国际惯例）**：涨/利好用红系，跌/利空用绿系，全篇一致；风险警报区保持红色警示

### 2.2 字体
- CJK 栈：`"PingFang SC","Source Han Sans SC","Noto Sans SC",sans-serif`
- 数字等宽：`SF Mono, JetBrains Mono, monospace`（价格、三价位、表格数字）

### 2.3 排版
- 8px 基线网格：间距/字号/圆角全部 8 的倍数；圆角 8px、柔和阴影
- 研究台风格：hairline 分隔线代替厚重卡片边框；克制装饰、信息密度优先
- 对比度 ≥ 4.5（WCAG AA）
- 单文件 HTML（SVG 内联不动，不引入外部 CDN）

### 2.4 结构强化（在现有 hero/清单/警报区基础上）
- 顶部 masthead 条：股票名 + 代码 + 报告日期 + 数据截止时点
- hero 行情区：现价大字等宽 + 涨跌幅 + 评分大字 + 三价位显式卡片
- 表格：zebra 条纹 + 数字右对齐等宽 + 长表 sticky 表头
- 页脚：免责声明 + 数据来源 + 生成时间
- 四张 SVG 统一标注数据时点
