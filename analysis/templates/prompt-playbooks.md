# A股数据 Skill 使用 Prompt 模板（10 套）

> 直接复制粘贴到 Hermes 即可触发本 skill。
> 设计原则：每个 prompt 都能让一个零经验的人 5 分钟内拿到想要的回答。

---

## 1. 单票完整估值（30 秒）

```
用 a-stock-data skill 给我做 600519 的完整估值：
- 实时价 / PE-TTM / PB / 市值
- 机构一致预期 EPS（今年 + 明年）
- 前向 PE / PEG / PE 消化到 30x 多少年
- 所属板块（行业 + 概念 + 地域）
- 近 20 日主力资金净流入
- 最近龙虎榜情况
- 最新融资余额 + 股东户数变化
按"壁垒 → 增速 → PE消化 → PEG 校验"框架给结论。
```

## 2. 题材轮动 + 资金验证（盘中）

```
今天 A 股市场怎么样？给我：
1. 当日强势股 TOP 20 + 题材归因（同花顺热点 reason 字段做词频统计）
2. 行业板块涨跌幅 TOP 10 + 资金流入 TOP 10
3. 沪股通 / 深股通北向资金当日累计净买入
4. 龙虎榜净买入 > 5000 万的票
5. 重点监控池 + 日内异动池（有没有交叉命中）
告诉我当下主线题材是什么，资金是否跟随。
```

## 3. 批量估值对比（选股）

```

输出：价 / PE-TTM / PE-前瞻 / PEG / PE消化年数 / 覆盖家数 / 所属板块
按 PE消化年数升序排序。
```

## 4. 主题研报检索

```
用 iwencai 给我搜"人形机器人 行星滚柱丝杠 2026"主题的研报：
- size=50（隐藏参数，默认 10 不够）
- 按发布日倒序
- 去重（同一 uid 只留 score 最高）
前 5 篇给我列：日期 / 机构 / 标题 / 涉及的股票代码。
如果有 688017、300476 等票命中，再用东财 reportapi 补一份个股研报 PDF 链接。
```

## 5. 宏观环境判断

```
现在流动性环境怎么样？用 a-stock-data 拉：
1. 最新社会融资规模增量（月度 12 列）—— 人民币贷款 / 政府债 / 企业债 各多少
2. 最新 PMI（制造业 / 非制造业 / 大中小型企业分档）
3. 跟最近 3 个月比，趋势是宽还是紧
这是看研报前必查的宏观底色。
```

## 7. 新标的快速调研（1 分钟）

```
我刚关注到 688017，用 a-stock-data 帮我做新标的快速调研：
1. 有无机构覆盖？一致预期 EPS？
2. 实时估值（PE/PB/市值/换手率/涨跌停价）
3. 所属板块（行业 + 概念 + 地域）
4. 当日资金流向 + 近 20 日主力累计
5. 龙虎榜（近 30 日上榜几次）
6. 未来 90 天限售解禁
7. 融资融券 + 大宗交易 + 股东户数 + 分红历史
8. 最近新闻 + 最近公告（巨潮）
9. V3.7 新增：筹码分布 CYQ（获利比例 / 平均成本 / 筹码峰）
10. V3.7 新增：估值历史（当前 PE 在过去几年分位）
11. V3.7 新增：申万行业变迁史（这个代码历史上换过几次行业？有没有前视偏差？）
最后给一个结论：能不能进观察池。
```

## 8. 北交所特殊处理

```
我要查 920xxx 北交所股票。注意：
- 优先用 920 新号段（老 832/836/838 已迁移，老码腾讯返回僵尸报价不报错！）
- baostock 不支持北交所 4/8/92/920 号段（会被服务端拒绝，代码里已 ValueError 拦截）
- 腾讯字段 43 不是 PB 是振幅%，46 才是 PB（网上教程都写错了）
- 拉 920982 / 920185 这些号段的腾讯行情时要检查 is_stale 字段
```

## 9. 东财防封铁律（任何批量任务）

```
我要批量拉 50 只票的龙虎榜 + 资金流。请遵守：
1. 串行不并发（绝不开多线程调东财）
2. 每只之间 sleep 1.5~2 秒（调大 EM_MIN_INTERVAL）
3. 复用 EM_SESSION（Keep-Alive）
4. UA + Referer 必须带
5. 走 em_get() 函数，不要裸 requests.get
6. push2his（120 日资金流）max_retries 设 6
7. 遇到 RemoteDisconnected / HTTP 000 —— 换网络（手机热点）或隔几分钟重试，不要死磕
```

## 附录：常用 ticker 写法

| 用户输入 | 归一化后 |
|----------|---------|
| 688017 | 688017 |
| SH688017 / sh688017 | 688017 |
| 688017.SH | 688017 |
| SZ000001 | 000001 |
| BJ832000 | 832000 |

**前 3 位决定市场：**
- 6/9 → sh（沪市）
- 8 → bj（北交所）
- 0/3 → sz（深市）
