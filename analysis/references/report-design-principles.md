# A 股报告生成：用户偏好与原则

> 强反馈（2026-09-03）：用户原话"现在的报告我看不懂"。
> 本文件是所有 A 股报告生成任务的**强约束**。

---

## 黄金顺序（4 段式）

任何 A 股分析输出都必须按这个顺序：

```
1. 🎯 一分钟结论
   ├─ 判断（能不能买 / 仓位 / 持仓周期）
   ├─ 具体点位（进场价区间 / 止损位 / 三档止盈）
   └─ 操作口诀（一句话记住怎么操作）

2. 👍/👎 信号清单（彩色 chip 形式）
   ├─ 看好这票的理由（每条带 +N 分）
   └─ 要小心的信号（每条带 -N 分）

3. 详细数据表 + 图表
   ├─ 估值（PE / PB / PEG / 一致预期 CAGR / 估值历史分位）
   ├─ 筹码分布（获利盘 / 平均成本 / 筹码峰 / 集中度）
   ├─ K 线 + 筹码图 + PE 历史 + 10 因子雷达
   └─ 实时行情 / 资金流 / 板块归属

4. 🎲 三种情景应对
   ├─ 涨了怎么卖（止盈 + 减仓节奏）
   ├─ 横盘怎么等（观察期 + 关键位）
   └─ 跌了怎么走（止损线 + 必走纪律）
```

**反例（用户看不懂的写法）**：
```markdown
# 宗申动力 001696
## 1. 实时行情
| PE(TTM) | 33.73 |
| PB | 3.52 |
| 涨跌 | +5.19% |
| 获利比例 | 81.89% |
```
只有数字，没有"该不该买 / 怎么买"。

## 数字翻译规则

### PE 阈值（人话）
| PE 区间 | 翻译 |
|---------|------|
| PE < 15 | 极低，便宜 |
| 15-25 | 偏低，估值有吸引力 |
| 25-40 | 合理，可接受 |
| 40-80 | 偏贵，要谨慎 |
| ≥ 80 | 极高估，泡沫风险 |

### PE 历史分位阈值
| 分位 % | 翻译 |
|--------|------|
| < 10 | 接近 3 年最低，便宜区间 |
| 10-30 | 便宜区间，可考虑 |
| 30-60 | 合理区间，不贵不便宜 |
| 60-80 | 偏贵区间，谨慎 |
| > 80 | 接近 3 年最高，泡沫区间 |

### PB 阈值
- PB < 2 → 极低
- 2-5 → 正常
- 5-10 → 偏高
- ≥ 10 → 极高

### PEG 阈值
- PEG < 1 → 便宜区
- 1-1.5 → 合理
- > 1.5 → 偏贵
- > 3 → 极贵（成长股例外：壁垒深可能合理）

### 机构覆盖数
- ≥ 5 家 → 覆盖足够，预期可信
- < 5 家 → 预期可能不准，谨慎参考

## 操作点位算法

### 仓位（按综合评分 100 分制）
| 评分 | 仓位建议 |
|------|----------|
| ≥ 75 | 可重仓 60-80% |
| 65-75 | 可建仓 30-50% |
| 55-65 | 轻仓试探 10-20% |
| 45-55 | 不进场 / 已有持仓减仓 |
| < 45 | 清仓回避 |

### 持仓周期（按一致预期 CAGR）
- CAGR ≥ 20% → 中线 3-6 个月
- CAGR ≥ 10% → 中线 1-3 个月
- CAGR < 10% → 短线 1-2 周

### 止损位算法
```
candidate_1 = 现价 × 0.93   # 默认 7% 止损
candidate_2 = 筹码峰 × 0.97  # 跌破筹码峰 +3% 缓冲
candidate_3 = 平均成本 × 0.97  # 跌破均成本 +3% 缓冲
止损 = min(candidate_1, max(candidate_2, candidate_3))
约束: 止损 > 现价 × 0.85（不能太离谱）
```

### 止盈三档
- 第一止盈：现价 × 1.10（+10%，先卖一半锁利）
- 第二止盈：现价 × 1.25（+25%，再卖一半）
- 第三止盈：现价 × 1.50（+50%，全仓走）

### 进场价区间
- 进场下限：现价 × 0.97
- 进场上限：现价

## 报告格式选择

| 输出场景 | 推荐格式 | 原因 |
|----------|---------|------|
| 终端查看 | Markdown | 简洁、可 grep |
| 移动端 | **HTML（单文件 + 内嵌 SVG）** | 图表直观、离线可看 |
| 邮件 | **HTML** | 单文件 29 KB，附件即可 |
| 微信分享 | **HTML** | 文件助手直接传，无需联网 |
| PDF 归档 | HTML + 浏览器打印 | 比 wkhtmltopdf 干净 |

### HTML 报告关键技术
- **图表必须用纯 SVG 手写**（不依赖 CDN/JS）
- 4 个核心图：K 线（蜡烛图）/ 筹码分布（柱图）/ PE 历史（折线）/ 10 因子雷达
- CSS 用内嵌（不引外部）
- 文件大小目标 < 50 KB（001696 实测 29 KB）
- viewport 适配移动端 + safe-area-inset 刘海屏安全区
- 字体 `-apple-system, BlinkMacSystemFont, "PingFang SC"`

## 报告配色（A 股惯例）

- **红涨绿跌**：K 线和涨跌幅必须用 #ef232a（红涨）/ #14b143（绿跌）
- **评分→颜色**：
  - ≥ 65 绿 #14b143（看多）
  - 55-65 橙 #ff9800（中性偏多）
  - 45-55 红橙 #ff5722（中性偏空）
  - < 45 红 #d32f2f（看空）
- **主调蓝 #2962ff**：标题/链接/图标
- **背景 #f5f6fa**：body
- **卡片白 #fff** + 阴影 0 1px 3px rgba(0,0,0,.05)

## 实现参考

- 报告生成器：`html_report.py`（540 行，4 SVG + HTML 模板）
- 打分引擎：`quant_analyzer_v2.py`（10 因子，1560 行）
- 5 个核心解读函数（必须复用，不要重写）：
  - `_interpret_pe(pe)` → 人话
  - `_interpret_pctile(pct)` → 人话
  - `_interpret_chips(cd)` → 4 条人话
  - `_make_trading_plan(q, v, cd, score_total)` → 进场/止损/止盈/仓位/周期
  - `_make_signal_list(s, factors)` → 看好/小心 列表

## 反模式（绝对不要做）

1. ❌ 直接给一堆数字（PE/PB/换手/振幅/...）就说"综合看可考虑"
2. ❌ 只给"建议买入/卖出"，不说**为什么**、不说**多少仓位**、不说**止损在哪**
3. ❌ 用 emoji 🟢🟢🟢 堆砌却不给具体数字
4. ❌ 把所有指标都列出来让用户自己判断（用户没耐心看）
5. ❌ 报告里出现未抓到的数据时直接留空，要明确说"申万表加载失败（SSL 过期，pip install -U certifi）"
6. ❌ 报告用 f-string 嵌三引号（参考 session-2026-09-03-lessons.md 第 2.1 节）
7. ❌ 报告依赖 CDN（chart.js / tailwind），用户离线打不开
