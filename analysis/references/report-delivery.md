# 报告交付原则 + 一键发布（a-stock-data V2.2 配套文档）

## 用户偏好（强约束）

用户明确反馈过 "现在的报告看不懂"——所有量化输出必须遵守：

### 1. 先给结论，再给数据
报告顶部必须有 **"🎯 一分钟结论"** 区块，包含：

| 字段 | 说明 | 示例 |
|------|------|------|
| 判断 | 一句话 | ✅ 可以建仓 / ⚠️ 轻仓试探 / ❌ 不建议进场 |
| 仓位 | 量化建议 | 可建仓 30-50% / 轻仓试探 10-20% / 清仓回避 |
| 进场价 | 具体点位 | 16.53 ~ 17.04 元 |
| 止损位 | 具体到分 | 14.94 元（跌 12.3% 必走）|
| 三档止盈 | +10%/+25%/+50% | 18.74 / 21.30 / 25.56 元 |
| 持仓周期 | 中/短线 | 中线 3-6 个月 |

### 2. 数字必须翻译成人话
- ❌ `PE 33.7` 单独摆着
- ✅ `PE 33.7 合理，可接受`
- ❌ `PE 分位 50.5%`
- ✅ `在历史 50.5% 分位（合理区间，不贵不便宜）`

PE 解读阈值：
| PE 范围 | 人话 |
|---------|------|
| < 15 | 极低，便宜 |
| 15-25 | 偏低，估值有吸引力 |
| 25-40 | 合理，可接受 |
| 40-80 | 偏贵，要谨慎 |
| > 80 | 极高估，泡沫风险 |

PE 分位解读阈值：
| 分位 | 人话 |
|------|------|
| < 10% | 接近 3 年最低，便宜区间 |
| 10-30% | 便宜区间，可考虑 |
| 30-60% | 合理区间，不贵不便宜 |
| 60-80% | 偏贵区间，谨慎 |
| > 80% | 接近 3 年最高，泡沫区间 |

### 3. 好/坏信号要分两栏
- 👍 看好这票的理由（绿色 chip）
- 👎 要小心的信号（红色 chip）
- 不要混在一坨因子明细里

### 4. 止损/止盈点位必须具体到小数点后 2 位
- ❌ "跌 7% 必走"
- ✅ "跌到 14.94 元 必走"

止损位计算策略（`make_trading_plan` 函数）：
1. 基础：`stop_loss = price * 0.93`（7% 默认止损）
2. 收紧：用筹码峰 + 平均成本 × 0.97 取更保守的（**更高的支撑位**，离场纪律比支撑更重要）
3. 保底：`stop_loss >= price * 0.85`（不能太紧，否则被正常波动震出）

### 5. 首选 HTML 报告（不要默认 Markdown）
- 微信可直接发文件，手机离线可看
- 单文件、内嵌 SVG、内嵌 CSS，**零 CDN / 零 JS 依赖**
- K 线 / 筹码峰 / 雷达图比表格易读 100 倍
- 文件大小控制 30-50 KB

### 6. 不要编造数据
所有数字必须真从接口拿取。接口不通时显示 `⚠️ 端点不可用`，**不要"演绎"或用模板填充**——这是用户多次明确强调的零容忍项。

## HTML 报告架构（推荐模板）

```
[蓝色渐变 header]
  股票名 / 代码 / 时间 / 价格 / 涨跌 / 综合评分 / emoji / 建议

[🎯 一分钟结论] (verdict 块)
  - 大字: ✅/⚠️/❌ + 一句话
  - 仓位 + 持仓周期
  - 表格: 进场价 / 止损 / 三档止盈
  - 💡 操作口诀 (白底半透明块, 整段建议)

[6 个 KPI 卡片] (2x3 grid)
  PE / PB / 前向PE / PE分位 / 获利盘 / 换手量比
  每个卡片: 标签 / 大数字 / 一行小字解读

[👍 看好理由] [👎 小心信号]
  flex-wrap chip 形式

[💰 估值贵不贵] (人话列表)
  PE / PB / PEG / 机构覆盖 / PE分位

[4 张 SVG 图] (grid-2 并排, 手机上下排)
  📈 K 线 (近 60 日) + 🎰 筹码分布
  📊 PE 历史 (近 6 月) + 🔬 10 因子雷达

[🎲 如果接下来…]
  涨 / 横 / 跌 三种情景应对

[📋 折叠详情表] (details/summary)
  实时行情 / 一致预期 / 估值历史 / 筹码明细

[⚠️ 免责声明 footer]
```

## 4 张 SVG 图实现要点

### 1. K 线 (svg_kline)
- 取最近 60 个交易日
- 红涨绿跌（**A股惯例，不是美股**）
- 当前价用橙色虚线 + 文字
- 价格标签贴右边
- 蜡烛宽度：`plot_w // n * 0.7` 至少 2px

### 2. 筹码分布 (svg_chip_histogram)
- 简化版: 三角分布（峰值在筹码峰）
- 红柱 = 现价之上 (套牢) / 绿柱 = 现价之下 (获利)
- 筹码峰蓝色虚线 + 文字
- 现价橙色虚线 + 文字
- 图例 "红=套牢盘 绿=获利盘"
- 用 `cd["cost_90"]` 作价格范围

### 3. PE 历史 (svg_pe_history)
- 取最近 180 个交易日
- 蓝色折线 + 起点绿点 + 终点橙点
- 5 条网格线 + 左侧价格标签
- 标题带 3 年分位数字

### 4. 10 因子雷达 (svg_radar)
- 10 维度: 趋势/估值/分位/资金/动量/情绪/风险/筹码/申万/龙虎榜
- 5 圈同心多边形 (网格)
- 数据多边形蓝色半透明 + 顶点圆 + 顶点分数
- 标签外移 18-22px
- 角度从 -π/2 开始（顶部为趋势）

## 🌐 一键发布到公网（GitHub Pages）

用户经常需要把 HTML 报告分享给朋友 / 发到微信 / 存到公网。**最快链路**：

```bash
# Step 1: 上传到 GitHub Gist (匿名公开)
gh gist create --public --desc "<股票> 量化分析报告" report.html
# → https://gist.github.com/<user>/<id>

# Step 2: ⚠️ htmlpreview.github.io 已失效 (2024 后 GitHub 改 API)
#         jsdelivr 不支持 Gist
#         0x0.st 因 botnet spam 关闭, transfer.sh 不可用
#         raw.githubusercontent.com 默认 Content-Type: text/plain
# → 唯一稳定方案: GitHub Pages

# Step 3: 建临时仓库 + 开 Pages (5-10 分钟)
gh repo create stock-report-viewer --public
gh api --method PUT repos/<user>/stock-report-viewer/contents/index.html \
  -f message="<股票> 量化分析报告" -f content=<base64_html>
gh api --method POST repos/<user>/stock-report-viewer/pages \
  -f source[branch]=main -f source[path]=/
# → 公网链接: https://<user>.github.io/stock-report-viewer/

# Step 4: 沙盒里 git push 会卡 60s (HTTPS 授权问题)
#         用 gh api PUT /contents/ 绕过
```

**等待时间**：GitHub Pages 首次部署需等 1-2 分钟才能访问。

**验证**：用 curl `https://<user>.github.io/<repo>/` 检查关键字符串（`✅ status=200`、`宗申动力 in body`）。

### 已知坑
- 沙盒 `git push` 经常 timeout，用 `gh api PUT /contents/` 替代
- Gist 默认 Content-Type 是 `text/plain`，**浏览器当文本显示不当 HTML 渲染**
- 报告里的数字（如止损价）只在生成时刻有效，**隔日必须重新生成**
